# Идея компании
EdTech-платформа для корпоративного обучения аналитиков на российском рынке, продуктовой, бизнес-, риск-, системной аналитике, продакт-менеджменту и которая будет доступна по подписке для компании.
Идея состоит в том, чтобы проанализировать 2 стороны: 

1. Какие навыки наиболее нужны компаниям на должность аналитика. Парсим данные с сайтов с вакансиями: для каждой вакансии сохраняем название, требования, опыт, зарплатная вилка, город, формат. Потом из требований извлекаем данные о необходимых навыках и анализируем частоту навыков и прирост к зарплате, который они дают. Источники: hh.ru, Habr Career, телеграмм-каналы с вакансиями. 
2. Каким навыкам уже обучают людей на рынке образования. Парсим данные курсов со Степика для каждого навыка из первого пункта и анализируем, сколько у них слушателей, какая суммарная выручка и т.д.

На основе этих данных можно будет проанализировать, какие скиллы в наибольшем дефиците (то есть больше всего нужны компаниям, а курсов по ним меньше всего) и далее на платформе сделать курсы, которые помогают прокачать эти скиллы.
