# Идея компании
EdTech-платформа для корпоративного обучения в малом и среднем бизнесе, на которой будут размещены уроки по маркетингу, продажам, аналитике, клиентскому сервису и управлению и которая будет доступна по подписке для компании.
Что можно поисследовать и какие данные собрать: целевая аудитория - собрать данные о том, какие категории бизнесов чаще всего испытывают трудности с квалификацией персонала и нуждаются в дополнительным образовании, и какие навыки в особом дефиците (данные опросов компаний и их руководителей, обзоры рынка труда); какие уже существуют платформы и насколько хорошо они работают (парсинг сайтов компаний и рейтингов уже существующих LMS); какие каналы маркетинга будут наиболее эффективными.
