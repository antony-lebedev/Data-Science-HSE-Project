# Идея компании
EdTech-платформа для корпоративного обучения аналитиков на российском рынке, продуктовой, бизнес-, риск-, системной аналитике, продакт-менеджменту и которая будет доступна по подписке для компании.
Идея состоит в том, чтобы проанализировать 2 стороны: (1) какие навыки наиболее нужны компаниям на должность аналитика (парсить сайты типа hh.ru с вакансиями аналитиков, для каждой вакансии писать нужные навыки); (2) какие навыки сейчас есть у людей, которые работают аналитиками или подаются на такие должности (парсить резюме с hh.ru, LinkedIn). На основе этих данных можно будет проанализировать, какие скиллы в наибольшем дефиците (то есть больше всего нужны компаниям, а у людей их меньше всего) и далее на платформе сделать курсы, которые помогают прокачать эти скиллы.
